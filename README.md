# TempoKeeper

Save video timestamps, clips and notes, and build multi-video playlists — a local-first Chrome extension.

TempoKeeper is distributed through the Chrome Web Store. This repository hosts its privacy policy and its public issue tracker.

- **Privacy policy:** [PRIVACY.md](PRIVACY.md)
- **Bug reports and feedback:** [open an issue](https://github.com/dimitriparadise/TempoKeeper/issues)
